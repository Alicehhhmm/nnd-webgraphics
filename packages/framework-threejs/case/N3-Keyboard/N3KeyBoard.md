# Description

通过 web3D 可视化的渲染形式，展示用户对键盘按键的操作

# Design Thought

在实现 threrJS 案例的过程中，突发奇想的想法

大概思路：

- 1.渲染一个一比一的标准键盘 3D 模型(存代码问题:不灵活，只有一个模型)
- 2.通过 JS 监听用户对键盘的操作
- 3.区分数字键盘，是否是小键盘上的
- 4.细节处理，按到的按键显示光环效果
- 5.拓展
  - 1.结合鼠标实现鼠标模型的移动
  - 2.屏幕模型
  - 3.将按键的内容输出展示到屏幕上
  - 4.显示传输线
  - 4.按键过程中实现传输动画（将内容通过线输入屏幕）
