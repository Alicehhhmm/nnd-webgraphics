# Three.js 学习指南

## 📚 概述

Three.js 是一个功能强大的 3D 库，它通过封装 WebGL 的复杂性，使开发者能够使用 JavaScript 创建令人惊叹的 3D 图形应用。本指南将带领您从基础概念到高级技巧，全面掌握 Three.js。

## 🎯 核心概念

Three.js 的核心由以下组件构成：

- **场景 (Scene)**: 3D 对象的容器
- **相机 (Camera)**: 观察 3D 世界的视角
- **渲染器 (Renderer)**: 将 3D 场景绘制到屏幕上
- **几何体 (Geometry)**: 定义对象的形状
- **材质 (Material)**: 定义对象的外观
- **灯光 (Light)**: 为场景提供照明
- **纹理 (Texture)**: 为对象表面添加细节
