# 资源总览

本页汇总了当前最实用、最受欢迎的 Web 图形学相关资源，旨在帮助 Web 2D/3D 开发者快速查找优秀的学习资料、引擎、工具与社区。

## 2D 资源

* [**PixiJS**](https://pixijs.com/) - 业界领先的 2D WebGL 渲染库。性能极高，擅长制作 2D 游戏、数据可视化和交互式图形。
* [**Konva.js**](https://konvajs.org/) - 一个用于桌面和移动应用的 2D 画布（Canvas）框架。擅长处理复杂的画布交互和对象模型。
* [**Fabric.js**](http://fabricjs.com/) - 强大且简单的 Javascript HTML5 Canvas 库。提供了交互式对象模型，非常适合构建在线编辑器。
* [**p5.js**](https://p5js.org/) - 面向艺术家、设计师和教育者的“创意编码”(Creative Coding)库，极易上手，社区活跃。
* [**SVG.js**](https://svgjs.dev/) - 一个轻量级的、用于操作 SVG 和制作动画的库。

## 3D 资源

* [**Three.js**](https://threejs.org/) - 目前最流行、生态最庞大的 Web 3D 库。它是一个渲染库，提供了构建 3D 场景所需的大部分工具。
* [**Babylon.js**](https://www.babylonjs.com/) - 由微软驱动的强大 3D 渲染引擎。以其易用性、完整的功能和出色的文档而闻名。
* [**A-Frame**](https://aframe.io/) - 一个基于 Three.js 的 WebVR 框架，使用 HTML 标签即可快速构建 VR 场景。
* [**Cesium**](https://cesium.com/platform/cesiumjs/) - 行业标准的 Web 3D 地球和地图（GIS）可视化引擎。

## 渲染引擎与平台

* [**PlayCanvas**](https://playcanvas.com/) - 一款功能强大的、基于云的 WebGL 游戏引擎和编辑器，支持团队协作。
* [**Cocos Creator**](https://www.cocos.com/creator) - 一套完整的 2D/3D 游戏开发解决方案，对 Web 平台支持良好，包含强大的编辑器。
* [**WebGL**](https://www.khronos.org/webgl/) - (底层 API) Web 图形库的底层标准。直接使用它非常复杂，但了解其原理很有帮助。
* [**WebGPU**](https://www.w3.org/gpu/) - (下一代 API) WebGL 的继任者，旨在提供更现代、更高效的 GPU 访问能力，性能更强。

## 学习资源

* [**MDN Web 图形**](https://developer.mozilla.org/zh-CN/docs/Web/Graphics) - MDN（Mozilla 开发者网络）的官方文档，是学习 WebGL 和 Canvas 基础的最佳起点。
* [**Three.js Journey**](https://threejs-journey.com/) - (付费) 被广泛认为是学习 Three.js 最好的课程，由 Bruno Simon 制作。
* [**The Book of Shaders**](https://thebookofshaders.com/) - (电子书) 学习 GLSL 着色器语言的入门经典，内容循序渐进。
* [**Babylon.js 文档**](https://doc.babylonjs.com/) - Babylon.js 的官方文档非常详细且对新手友好，包含大量可交互的示例。
* [**WebGL 基础**](https://webglfundamentals.org/) - (WebGL Fundamentals) 深入讲解 WebGL 原理的网站，适合希望理解底层的开发者。

## 工具资源

* [**Blender**](https://www.blender.org/) - 免费且开源的 3D 建模、动画和渲染软件。Web 3D 开发必备。
* [**Spector.js**](https://spector.babylonjs.com/) - (浏览器插件) 用于调试 WebGL/WebGPU 场景的利器，可以逐帧分析渲染调用。
* [**gltf-viewer**](https://gltf-viewer.donmccurdy.com/) - (网页工具) 一个简洁的在线 glTF 模型查看器，用于快速检查模型文件。
* [**glTF**](https://www.khronos.org/gltf/) - (文件格式) Web 3D 的“JPEG”。一种为 Web 优化的 3D 模型格式标准，由 Khronos 组织维护。

## 社区资源

* [**Three.js 官方论坛**](https://discourse.threejs.org/) - 寻求 Three.js 帮助和分享作品的主要社区。
* [**Babylon.js 官方论坛**](https://forum.babylonjs.com/) - Babylon.js 官方社区，非常活跃，官方团队回复积极。
* [**Stack Overflow (webgl 标签)**](https://stackoverflow.com/questions/tagged/webgl) - 解决具体编程问题的首选问答网站。
* [**掘金 (图形学标签)**](https://juejin.cn/tag/%E5%9B%BE%E5%BD%A2%E5%AD%A6) - 中文技术社区，有许多关于 WebGL 和 Three.js 的优质文章。
* [**r/webgl (Reddit)**](https://www.reddit.com/r/webgl/) - 国际性的 WebGL 开发者社区，用于分享项目和讨论技术。

## 教学视频

* [**Babylon.js 官方 YouTube**](https://www.youtube.com/c/BabylonJS) - 包含大量官方教程、更新介绍和案例分析。
* [**The Coding Train**](https://www.youtube.com/c/TheCodingTrain) - (YouTube 频道) Daniel Shiffman 的频道，涵盖 p5.js、WebGL 等创意编码内容，非常适合初学者。
* [**Bilibili (B站)**](https://www.bilibili.com/) - B站有大量中文 Web 图形学教程，搜索 "Three.js"、"WebGL" 或 "p5.js" 可以找到。
