# 资源总览

为方便 Web2D/3D 开发者快速查找优秀的学习资料、引擎、工具与社区，本页汇总了当前最实用、最受欢迎的 Web 图形学相关资源。

## 2D 资源

### 2D 渲染库

- [PixiJS](https://pixijs.com/) - 快速、轻量的 2D WebGL 渲染引擎，适合游戏和交互式图形
- [Fabric.js](http://fabricjs.com/) - 强大的 HTML5 Canvas 库，提供交互式对象模型
- [Paper.js](http://paperjs.org/) - 基于 HTML5 Canvas 的矢量图形脚本框架
- [Konva.js](https://konvajs.org/) - 用于桌面和移动应用的 2D Canvas 框架
- [Two.js](https://two.js.org/) - 面向现代浏览器的二维绘图 API
- [p5.js](https://p5js.org/) - 创意编码库，让艺术家、设计师易于上手

### 2D 动画库

- [GSAP](https://gsap.com/) - 专业级 JavaScript 动画库，性能强大
- [Anime.js](https://animejs.com/) - 轻量级 JavaScript 动画库
- [Velocity.js](http://velocityjs.org/) - 加速的 JavaScript 动画引擎
- [Lottie](https://airbnb.io/lottie/) - Airbnb 开源的动画库，支持 After Effects 动画

### 2D 图表库

- [D3.js](https://d3js.org/) - 数据驱动的文档操作库，强大的数据可视化工具
- [Chart.js](https://www.chartjs.org/) - 简单而灵活的 JavaScript 图表库
- [ECharts](https://echarts.apache.org/) - Apache 开源的强大可视化库
- [Plotly.js](https://plotly.com/javascript/) - 开源的声明式图表库

## 3D 资源

### 3D 核心库

- [Three.js](https://threejs.org/) - 最流行的 WebGL 3D 库，功能全面
- [Babylon.js](https://www.babylonjs.com/) - 强大的 3D 游戏引擎，支持物理引擎和 VR/AR
- [A-Frame](https://aframe.io/) - Mozilla 开发的 WebVR 框架，基于 HTML 语法
- [PlayCanvas](https://playcanvas.com/) - 开源的 3D 游戏引擎，提供在线编辑器
- [Cesium.js](https://cesium.com/platform/cesiumjs/) - 开源的 3D 地球和地图可视化库

### 3D 工具库

- [React Three Fiber](https://docs.pmnd.rs/react-three-fiber/) - Three.js 的 React 渲染器
- [Drei](https://github.com/pmndrs/drei) - React Three Fiber 的有用助手集合
- [Leva](https://github.com/pmndrs/leva) - React 的 GUI 控制面板
- [Three.js Editor](https://threejs.org/editor/) - Three.js 官方在线 3D 场景编辑器
- [Spline](https://spline.design/) - 浏览器中的 3D 设计工具

### 3D 物理引擎

- [Cannon.js](https://github.com/schteppe/cannon.js) - 轻量级 3D 物理引擎
- [Ammo.js](https://github.com/kripken/ammo.js) - Bullet 物理引擎的 JavaScript 移植
- [Rapier](https://rapier.rs/) - 快速的 2D/3D 物理引擎（Rust/WASM）
- [Oimo.js](https://github.com/lo-th/Oimo.js) - 轻量级 3D 物理引擎

## 渲染引擎资源

### WebGL 框架

- [regl](https://github.com/regl-project/regl) - 函数式 WebGL 框架
- [TWGL](https://twgljs.org/) - 简化 WebGL 开发的小型库
- [ClayGL](http://claygl.xyz/) - 用于构建可扩展 3D 应用的 WebGL 图形库
- [OGL](https://github.com/oframe/ogl) - 最小的 WebGL 库

### WebGPU

- [WebGPU Fundamentals](https://webgpufundamentals.org/) - WebGPU 基础教程
- [wgpu](https://wgpu.rs/) - 基于 WebGPU API 的跨平台图形库
- [Dawn](https://dawn.googlesource.com/dawn) - Google 的 WebGPU 实现
- [Babylon.js WebGPU](https://doc.babylonjs.com/setup/support/webGPU) - Babylon.js 的 WebGPU 支持

### 着色器工具

- [ShaderToy](https://www.shadertoy.com/) - 在线着色器创作和分享平台
- [The Book of Shaders](https://thebookofshaders.com/) - 片段着色器入门指南
- [glslCanvas](https://github.com/patriciogonzalezvivo/glslCanvas) - 简单的 GLSL 着色器预览工具
- [Shaderfrog](https://shaderfrog.com/) - 在线着色器编辑器和材质库
