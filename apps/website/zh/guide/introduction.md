# 为什么要写这个文档？

## 前言

在现代前端开发中，Web 图形技术已经成为了构建丰富、互动用户体验的核心技能。从简单的数据可视化到复杂的 3D 游戏，从移动应用的动画效果到沉浸式虚拟现实体验，Web 图形技术的应用越来越广泛。

然而，Web 图形技术的学习曲线陡峭，相关知识分散在各个文档、教程和实践中。许多开发者在学习过程中常常遇到以下挑战：

- **技术栈复杂**：从基础的 Canvas、SVG 到 3D 技术如 WebGL、WebGPU，再到各种渲染引擎如 Three.js、Babylon.js
- **信息碎片化**：相关知识分布在不同的文档、博客、教程中，缺乏系统性
- **实践指导不足**：理论知识丰富但缺少实际项目经验

## 目标

我们创建这个文档的目标是：

1. **系统化整理**：将 Web 图形相关的知识按照技术栈进行系统化整理
2. **实践导向**：不仅提供理论知识，更注重实际应用和最佳实践
3. **持续更新**：随着 Web 图形技术的发展，持续更新和补充相关内容

## 我们的愿景

我们希望这个文档能够成为：
- Web 图形开发者的参考手册
- 学习 Web 图形技术的起点
- 实践中的问题解决指南

希望通过本站点，帮助更多开发者深入了解和掌握web图形相关技术。
